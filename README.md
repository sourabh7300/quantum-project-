# ⚛️ Quantum Circuit Simulator

> Design quantum circuits and watch superposition and entanglement play out — right in your browser.

**🔴 Live demo:** https://sourabh7300.github.io/quantum-project-/

## What it does
- Place gates (H, X, Z, CNOT and more) on a visual circuit board
- State-vector simulation with real amplitude math
- Measurement with probabilistic collapse, run repeatedly
- Built for learning: every concept is one click deep

## Built with
HTML · CSS · JavaScript — **zero frameworks**, single file, runs in any browser.
